# Vishesh Jewellers v1.2.2

Includes encrypted SQLite storage, username/password accounts and roles, store branding, portable encrypted backup/recovery, a full-feature 14-day trial, and store-bound signed paid activation. See the [feature and upgrade notes](https://github.com/aditya6677/vishesh-jewellers/blob/v1.2.2/release-notes/v1.2.0.md).

Release fixes include Windows line-ending compatibility, universal Mac database packaging, and Windows database-test cleanup order.

Installers are unsigned. Back up and verify recovery before upgrading. Existing JSON installations are not silently migrated; the separate Test app's data is not automatically imported. Keep your backup passphrase separately. No vendor private signing key or business data is bundled.
