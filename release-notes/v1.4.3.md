## Upgrade safely

Create and verify an off-device portable encrypted backup; keep its complete folder and recovery passphrase separately. Existing JSON installations are not silently migrated, and separate Test-app data is not automatically imported.

Installers retain the **Vishesh Jewellers** app/binary name and application ID for existing installation/data compatibility. The product is **KaratDesk by Tech Aditya**. Existing stores may need an Owner/Superadmin licence review without resetting records. Reads, exports and backups remain available subject to permissions.

Invoice calculation rules are unchanged. Software reversals do not physically refund money or return metal.

## Installer checks and compatibility

Windows x64 EXE and universal macOS DMG are **unsigned**. Keep antivirus enabled, use the official release links and verify SHA-256 with `SHA256SUMS.txt`.

Both platforms must pass the financial/account/backup regression tests, legacy compatibility tests, native OS-protected key and setup/recovery checks, and packaged runtime/database checks before publication. No customer data, private licence-signing key or developer database key is bundled.

Modern Electron does not support Windows 7. Core operations work offline; fresh market data and downloads need internet. Offline licensing is not guaranteed prevention of local tampering or complete trial-data removal.
