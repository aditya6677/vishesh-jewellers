## Before upgrading

Create and verify an off-device portable encrypted backup; keep the whole backup folder and recovery passphrase separately. Existing JSON installations are not silently migrated. Separate Test-app data is not automatically imported.

Installers retain the **Vishesh Jewellers** binary/display name and application ID to preserve upgrade/data identity. **KaratDesk by Tech Aditya** is the product name. Existing stores may require an Owner/Superadmin licence review without resetting their records. Reads, exports and backups remain available subject to permissions.

Invoice calculation rules are unchanged. Reversals in software do not physically refund cash or return metal.

## Verification and compatibility

Both installers are **unsigned**. Keep antivirus enabled, use the official links and verify SHA-256 against `SHA256SUMS.txt`. Windows x64 and universal macOS builds are published only after CI tests, native OS-key/setup/recovery checks and packaged runtime/database verification pass on both platforms. No customer data, private licence-signing key or developer database key is bundled.

Modern Electron does not support Windows 7. Core operations work offline; fresh benchmarks and installer downloads need connectivity. Offline licensing is not guaranteed protection against local tampering or complete trial-data removal.
