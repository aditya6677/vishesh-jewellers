## Vishesh Jewellers 1.1.1

### Improvements
- Consistent invoice-number, payment-reason, search and editor input styling.
- Improved keyboard focus, disabled controls, tablet navigation and invoice layout.
- Regression checks prevent missing input types and default native dropdowns.

### Included application features
- React interface by default, with explicit `?frontend=legacy` compatibility mode.
- IBJA Gold/Silver rate history chart and workspace logout.
- Encrypted local data, backup/restore, stock, invoices, settlements, purchases and payments.

### Downloads
- Windows x64 NSIS installer (`.exe`). Windows 7 is not supported.
- macOS universal disk image (`.dmg`) for Intel and Apple Silicon.
- `SHA256SUMS.txt` to verify installer downloads.

**Unsigned release:** these installers are not code-signed or Apple-notarized.
Operating-system security warnings may appear. Do not disable security protections.
The existing workspace PIN remains 5512; it is a convenience lock, not multi-user
authentication. Do not expose the local app server to the public internet.

Back up your data and matching encryption key before upgrading. Installers do not
contain business data and do not import browser data into the desktop app.

Both backend test suites and packaged-runtime checks must pass on GitHub runners
before this release is published. Prior local checks passed all 118 tests per
backend; browser tests covered stock, sale, settlement, edit and void reversal.
