# KaratDesk 1.8.0

- Daily portable encrypted backups: enable in Settings for existing stores. New stores configure them during onboarding. Overdue backups run at startup; no automatic deletion or cloud upload is enabled.
- Settings shows the ongoing backup folder, last successful run, next due time and failures. The initial setup snapshot is shown separately when known.
- New paid activation codes default to a 365-day term. Previously issued licences retain their terms. Expired stores can still read records, export and back up.
- Added support contact links and refined Settings, light mode and the licence reader.

Create and verify a portable backup before upgrading. Keep the recovery passphrase separately. Windows and macOS installers are unsigned; SHA-256 checksums are included.
