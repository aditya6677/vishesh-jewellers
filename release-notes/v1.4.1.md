# KaratDesk by Tech Aditya - v1.4.1

Includes all v1.4.0 improvements: desktop workspace and fitted invoice preview, unsaved-draft protection, light/dark UI refinements, clearer Superadmin administration, safe startup recovery, offline Legal & Support, encrypted administrator acceptance evidence, and verified paid-plan review.

This release updates the packaged acceptance test to follow the new licence-acceptance setup flow and checks that acceptance survives portable recovery.

## Before upgrading

- Create and verify an off-device portable encrypted backup. Keep its recovery passphrase separately.
- Installers retain the **Vishesh Jewellers** app/binary name and application ID for compatibility with existing data locations. **KaratDesk by Tech Aditya** is the product identity.
- Existing stores may need an Owner/Superadmin licence review. This does not reset records; existing reads, exports and backups remain available subject to permissions.
- Existing JSON installations are not silently migrated. The separate Test app's data is not imported automatically.
- Invoice calculation rules are unchanged. Software reversal does not physically return cash or metal.

## Downloads and verification

Windows x64 EXE and universal macOS DMG are **unsigned**. Keep antivirus enabled, verify the official download source and compare the installer SHA-256 with `SHA256SUMS.txt`.

GitHub Actions must pass the financial/account/backup tests, legacy compatibility tests, native OS-key and setup/recovery checks, and packaged runtime/database checks on both Windows and macOS before publishing. Customer records, private licence-signing keys and developer data keys are not included.

Modern Electron does not support Windows 7. Core operations work offline; fetching fresh benchmarks and downloading installers require internet. Offline licences do not guarantee prevention of local tampering or trial reset after complete data removal.
