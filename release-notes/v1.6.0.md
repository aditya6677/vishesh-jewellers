# KaratDesk 1.6.0

## Import data from an older app version
- New Settings wizard to preview and import older encrypted JSON business data into a new, empty SQLite store.
- Native desktop file selection uses an existing matching key without modifying original files or exposing keys to the renderer.
- Create and open password-protected portable legacy files for moving data between computers.
- Review record counts, stock balances, financial totals, historical-format warnings and the next invoice number before confirming.
- Create an encrypted safety backup before import; commit business records atomically and verify exact records and financial summaries.
- Preserve destination accounts, roles, legal acceptance and licensing. Prevent duplicate imports and imports into populated stores.
- Keep historical invoice values and Gold classification unchanged; advance invoice numbering when necessary to avoid reuse.

The original computer and OS account may be required to unlock older desktop data. Keep the old app, data and matching key until migration is verified. This feature does not merge populated stores or automatically convert an existing JSON installation to SQLite. See LEGACY-IMPORT.md for steps and size limits.

Installers are unsigned. Back up existing data before updating; operating systems may display a publisher warning.
