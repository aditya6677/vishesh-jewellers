## Data and compatibility

KaratDesk is the product name. These installers retain the legacy **Vishesh Jewellers** app/binary name and application ID to avoid silently changing existing installation/data identity. Store branding remains customisable.

Back up and verify portable recovery before upgrading. Keep the whole portable backup folder and its recovery passphrase separately. Existing JSON installations are not silently migrated, and data in a separate Test app is not automatically imported.

Existing database stores may require one authorised Owner/Superadmin licence review. This does not reset records; reads, exports and backups remain available subject to existing access controls. Invoice calculations remain unchanged.

## Installer verification

Windows x64 EXE and universal macOS DMG installers are **unsigned**. Verify SHA256SUMS.txt and the official download source. Keep antivirus enabled. Windows 7 is not supported by the bundled modern Electron runtime.

The release workflow runs the financial/account/backup regression suites on both Windows and macOS, OS-protected key and setup/recovery checks, and packaged runtime/database verification before publishing either installer. No customer data, private licence-signing key or developer database key is bundled.

Core operations run locally/offline. Fresh market benchmarks, downloading installers and contacting support require connectivity. Offline licensing is not a guarantee against local tampering or complete trial-data removal.
