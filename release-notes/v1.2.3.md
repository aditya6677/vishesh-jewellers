# Vishesh Jewellers v1.2.3

## Features

- Encrypted SQLite storage, transactional financial operations and indexed reporting/pagination.
- Username/password accounts, Superadmin setup, roles, permissions, session controls and audit history.
- Store name, tagline and logo customization.
- Encrypted portable backups, guarded recovery, configurable backup folder and weekly safety copies.
- A full-feature 14-day trial and signed store-bound paid activation without clearing records.

## Release fixes

- Windows line-ending compatibility and database-test cleanup.
- Universal macOS packaging of encrypted database binaries.
- Windows build-shell handling of installer configuration arguments.

## Before installing

Installers are **unsigned**. Back up and verify recovery before upgrading. Existing JSON installations are not silently migrated; the separate Test app's data is not automatically imported. Keep your backup passphrase separately. No vendor private signing key or business data is bundled.

Offline licensing does not provide online revocation or guaranteed prevention of trial resets after complete local data removal. See the [full upgrade and licensing notes](https://github.com/aditya6677/vishesh-jewellers/blob/v1.2.3/release-notes/v1.2.0.md).
