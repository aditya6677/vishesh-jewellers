# Vishesh Jewellers v1.2.0

## New

- Encrypted SQLite storage with transactional financial operations, indexed pagination and report queries.
- Username/password login, first-Superadmin setup, Owner/Admin/Staff permissions, password resets, session controls and audit history.
- Superadmin store name, tagline and raster-logo customization for the workspace and new invoices.
- Fresh-install setup with recovery passphrase and initial encrypted backup.
- Portable encrypted backup import, verification and guarded restore; configurable backup folder and weekly safety copies.
- A 14-day full-feature trial starting after administrator setup, with no trial invoice cap.
- Store-bound signed paid activation, optional expiry and lifetime invoice allowance. Records, exports and backups remain accessible after expiry.
- Account-page UI improvements, password visibility controls and custom dropdowns.

## Installation and upgrade notes

These are **unsigned installers**, not signed/notarized production certificates. macOS/Windows may display publisher/security warnings. Do not disable system security protections. Verify installer checksums in SHA256SUMS.txt.

Fresh desktop installations use encrypted database setup. Existing JSON desktop installations retain their established storage/startup path; this update does **not** silently migrate or replace business data. Back up and verify recovery before upgrading. Existing migrated databases retain their configuration and data. Native end-user GUI installation/upgrade testing remains separate from automated CI/backend checks.

The real application is named **Vishesh Jewellers**; the separately distributed **Vishesh Jewellers Test** app has a different data folder. Test-store data is not automatically imported into the real application.

The vendor public verification key is bundled. Vendor private signing keys, business data and passwords are not included. A valid paid activation is applied in Settings without reinstalling or clearing records. Create a new portable backup after account/license changes and keep its recovery passphrase separately.

## Licensing limitations

Licensing is offline. It does not guarantee one trial per physical device, online revocation or prevention of resets after complete removal of local installation data. Strict enforcement requires a vendor activation service. Forgotten last-Superadmin-password recovery is not yet a self-service feature; no hidden/default password is provided.

Build gates cover financial regression tests, native OS-key/setup checks and packaged runtime/database recovery. Native GUI acceptance on every supported OS/hardware combination is not implied by a passing build. See LICENSING.md, ACCOUNT-MIGRATION.md and DESKTOP-ACCEPTANCE.md in the source for details.
