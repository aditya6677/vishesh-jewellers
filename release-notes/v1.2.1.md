# Vishesh Jewellers v1.2.1

Includes the encrypted database, account/role management, store branding, encrypted backup/recovery and 14-day trial/paid activation features described in [v1.2.0 release notes](https://github.com/aditya6677/vishesh-jewellers/blob/v1.2.1/release-notes/v1.2.0.md).

- Fixes Windows source line-ending compatibility in the invoice renderer.
- Fixes universal macOS packaging of the architecture-specific encrypted database binaries.

Installers are unsigned. Back up and verify recovery before upgrading. Existing JSON installations are not silently migrated; the separate Test app's data is not automatically imported. Keep your backup passphrase separately. No vendor private signing key or business data is bundled.
